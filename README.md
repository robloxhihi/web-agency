# SkyWeb Studio — Dịch Vụ Thiết Kế & Lập Trình Website Đẳng Cấp

Website giới thiệu dịch vụ thiết kế và lập trình website cao cấp, chuẩn UI/UX, tối ưu chuyển đổi tối đa với hiệu ứng chuyển động (motion animation) mượt mà 60 FPS.

---

## 🌟 Điểm Nổi Bật

- **Tối ưu chuyển đổi (High-Converting CRO)**: Thiết kế các nút Call-To-Action (CTA) nổi bật, dẫn thẳng về Facebook Messenger cá nhân để chốt đơn: **[fb.com/sky.real.2025](https://www.facebook.com/sky.real.2025)**.
- **Giao diện độc bản (Dark Luxury Editorial)**: Tone màu Obsidian Deep Void `#08090E`, Neon Indigo `#6366F1` kết hợp Cyber Emerald `#10B981` sang trọng, đẳng cấp.
- **Bảng tính chi phí tương tác (Interactive Pricing Calculator)**: Khách hàng có thể tự chọn loại website và tính năng phụ trợ để dự toán chi phí minh bạch tức thì.
- **Hiệu ứng chuyển động (Natural Web Animations)**: 
  - Vận dụng chuẩn `web-animation-design` và `frontend-design`.
  - Floating Ambient Mesh Orbs nhẹ nhàng.
  - Social Proof Toast Notification (thông báo khách hàng đăng ký theo thời gian thực).
- **Responsive 100%**: Hoạt động mượt mà trên iPhone, Android, iPad và Màn hình Retina Desktop.
- **Chuẩn Accessibility (A11y)**: Độ tương phản văn bản đạt WCAG 2.1 AA, Focus Ring rõ ràng, tối ưu tốc độ tải trang dưới 1s.

---

## 🛠 Công Nghệ Sử Dụng

- **HTML5 & Semantic Structure**
- **Tailwind CSS 3.x (JIT)**
- **Lucide Icons Library** (SVG Icons sắc nét, không dùng emoji làm icon)
- **Google Fonts**: `Syne` (Heading) & `Plus Jakarta Sans` (Body Text)
- **JavaScript ES6+**: Xử lý tính toán bảng giá, toast thông báo và tương tác trực quan.

---

## 🚀 Hướng Dẫn Chạy Thử Nghiệm

Mở trực tiếp file `index.html` trong trình duyệt web bất kỳ (Chrome, Edge, Safari, Firefox), hoặc sử dụng Live Server trong VS Code:

```bash
# Sử dụng npx serve hoặc live-server
npx serve .
```
